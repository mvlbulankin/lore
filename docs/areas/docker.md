# Docker

**Files:** `Dockerfile`, `docker-compose.yml`

## Image

Based on `python:3.14-slim` with `uv` copied from `ghcr.io/astral-sh/uv:latest`. Final image size is ~360MB.

### Build Layers

1. Base Python 3.14 slim + uv
2. System deps: `curl` (for healthcheck)
3. Lock file sync: `uv sync --frozen` (cached layer)
4. Application code: `docs_shared/`, `ingestion/`, `app/`
5. Non-root user: `app` (created with home dir and bash shell)
6. Environment: `PYTHONPATH=/app:/app/ingestion`, `PATH` includes `.venv/bin`

### Entrypoint

```bash
python -m uvicorn app.server:app --host 0.0.0.0 --port 8000
```

## Volume Mounts

| Mount | Direction | Purpose |
|-------|-----------|---------|
| `./data:/data` | read-write | ChromaDB persistent storage, BM25 index |
| `./data/prepared:/data/prepared:ro` | read-only | Prepared documents (served to ingestion) |

The `data` directory on the host contains three sub-mounts:
- `data/chroma/` — ChromaDB persistent storage
- `data/prepared/` — prepared documents (read-only inside container)
- `data/bm25.pkl` — BM25 index file (generated by ingestion)

## Port Mapping

Container exposes port 8000, mapped to host port 8000. Server binds to `0.0.0.0`.

## LM Studio Connectivity

The container reaches LM Studio at `host.docker.internal:1234`. This DNS name resolves to the host machine, allowing the container to call the LM Studio API running on the host. This is the only external network dependency.

## Healthcheck

Docker healthcheck curls `http://localhost:8000/health` every 10s with 5s timeout and 5 retry attempts.

## PYTHONPATH

Set to `/app:/app/ingestion` so that:
- `docs_shared` is importable as a top-level package
- `ingestion/` modules (chunker, embedder, bm25_index) are importable directly
- `app/` is the uvicorn working directory

## Security Notes

- Container creates a non-root `app` user but runs as root to write to host-owned volume mounts
- For production deployments, use UID-mapped volumes to run as the `app` user
- No external network access except to LM Studio host
